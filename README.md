# Knox Hill: Project NORJAK // D.B. Cooper Case File Archive

> *"From the pitch to the mic—and into history's greatest cold case."*

This repository contains the source code for the custom landing page and interactive case file experience for **Project NORJAK**—a promotional concept site dedicated to Knox Hill's upcoming single, ***D.B. Cooper*** (feat. Crypt), dropping **September 25th**.

---

## 🚁 The Narrative Concept: Project NORJAK

On November 24, 1971, an unidentified man calling himself D.B. Cooper hijacked Boeing 727 Flight 305, extorted $200,000 in ransom, and parachuted into the Pacific Northwest night—never to be seen again. The FBI code-named the investigation **NORJAK** (*Northwest Hijacking*).

In this release campaign, Knox Hill channels the untraceable persona of D.B. Cooper, drawing parallels between history’s most infamous vanishing act and his own relentless, independent push through hip-hop, athletic competition, and high-level content creation.

---

## 📁 What’s Inside the Archive

The repository features an immersive, dark-mode **Corkboard Investigation Dossier** built directly in `index.html`:

* **Classified Field Header**: Real-time status indicators and release countdown timers mimicking FBI case documents.
* **Vertical Teaser Trailer Integration**: Embedded 9:16 vertical video preview showcasing the official campaign teaser ("The Manhunt Continues...").
* **Interactive Evidence Grid (Corkboard)**:
  * **Exhibit A (Lyricist)**: Technical fast-flow structures, storytelling depth, and wordplay breakdowns.
  * **Exhibit B (Athlete)**: Professional soccer background spanning England (AFC Fylde), Italy, Spain, Malta, and Canada.
  * **Exhibit C (Analyst)**: Tactical ex-pro breakdown experience powering content for over 950K YouTube subscribers.
* **Redacted Intelligence Mode**: Hover-to-decrypt interactive text elements built into suspect files.
* **Verified Receipts Section**: Direct links to external coverage, interviews (*UrbanPitch*, *Merrick Creative*), viral video analysis, and footwork archives.
* **Dossier Action CTA**: Direct pre-save portal routing listeners to official streaming links prior to the September 25th worldwide premier.

## 🛠️ Tech Stack & Design Identity

* **HTML5 & Vanilla CSS3**: Zero heavy external CSS frameworks. Engineered for low overhead and fast static delivery on open infrastructure.
* **Typography**: 
  * `Bebas Neue` (Bold stencil display headers)
  * `Courier Prime` (Teletype & FBI field notes body font)
  * `Special Elite` (Typewriter classification stamps)
* **GitHub Pages**: Free, decentralized static hosting providing full data sovereignty independent of third-party platform algorithms.

---

## 📝 Obsidian.md Archive Protocol

To secure intellectual property and maintain creator-owned knowledge management:
* **Local Data Sovereignty**: All lyrical drafts, tactical breakdown notes, and video storyboards are maintained in plain-text Markdown (`.md`) files on local storage.
* **Interconnected Graphing**: Linking historical research (NORJAK case details), tactical sports diagrams, and song structures inside a personal knowledge base.
